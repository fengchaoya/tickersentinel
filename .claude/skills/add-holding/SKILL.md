# 新增持仓：在 Claude Code 里准备联动候选

`tsen scope add` 会给新持仓找联动：Yahoo 相似股票、Finnhub 同业、已有主题的海外代码，再加上“大模型提名”的候选
（海外对应公司、大客户、检索词……），然后用近一年的日线逐个打分，留下真正联动的。大模型提名这一步交给你
（Claude Code，用读者的订阅额度），不调用 API：你写好候选文件，程序自动读取。候选只是提名，最后由数据决定。

## 步骤

命令都在项目根目录运行；找不到 `tsen` 时用 `.venv/bin/tsen`。

1. **弄清要加什么**：代码用 Yahoo Finance 格式（海外带交易所后缀：.KS 首尔、.T 东京、.SZ / .SS 深圳上海、.HK 香港、.TW 台湾）。
   读者要并入某个已有主题时记下主题名（`--theme 主题key`）。先运行 `tsen scope` 看现在的范围。
   只有美股 / 美股 ADR 才找联动：海外股票、期货、加密货币用 `tsen scope add` 只按类别默认阈值加入，不读候选文件——
   跳过第 2–4 步；需要联动时手工写进某个主题的 overnight / peers。
2. **拿上下文**：运行 `tsen scope prompt 代码`。它打印 Yahoo 资料、相似股票、已有主题、提名要求、输出格式和候选文件的路径。
3. **找候选**：按打印的要求，用你自己的知识整理；用 WebSearch 核实没把握的代码和最新情况（新上市、改名、拆分、退市；
   海外代码的后缀和数字）。只给有把握的代码，不要编造；各类的数量上限见要求。
   - 海外对应公司最要紧：美股休市时（美东约 20:00–次日 04:00），它们的走势是持仓的“夜间信号”。
   - 新闻检索词写行业关键词，不写公司名；公司自己的检索词放 `company_queries`。
4. **写文件**：用 Write 把 JSON 写到第 2 步打印的路径（`data/scope_candidates/代码.json`，`data/` 不进 git）。
5. **预览**：运行 `tsen scope add 代码 [--theme 主题key]`（在 Claude Code 里只预览、不写入）。约 10–30 秒，打印：
   并入已有主题还是新建、板块基准的 R²、同业（剔除大盘后的残差相关）、夜间信号（对次日开盘跳空的偏相关）、
   相关公司、建议的警报标准、配置会有哪些变化、回放最近 5 个交易日会推送几条。
   用中文向读者简要汇报：留下了什么、为什么；你提名但被数据剔除的也说一句（打分结果比提名更可信）。
6. **按读者意见调整**：去掉候选用 `--drop A,B`，加回默认不选的用 `--keep C`；要换提名就改候选文件，再预览一次。
7. **读者明确确认后才写入**：`tsen scope add 代码 --yes --replay-days 0`（带上第 6 步用过的 `--theme` / `--drop` / `--keep`）。
   写入的是正在用的那份配置里的 `assets.yaml` 和 `themes/`（`.env` 里设了 `TICKERSENTINEL_SETTINGS` 时是它指向的目录，
   一般是不进 git 的 `config.local/`；没设时是仓库里的示例 `config/`）；正在运行的 `tsen run` 一分钟内自动生效，不用重启；
   `tsen scope undo` 撤销。不要手改这些配置文件，不要自动提交 git（读者要求时再提交）。

读者也可以只让你准备候选（第 1–4 步），之后在手机飞书里发 `/scope add 代码`：同一份候选文件 30 天内都会用上。

## 其他相关命令

- 移除持仓：`tsen scope remove 代码` 预览，读者确认后加 `--yes`（主题文件保留备用）。
- 调警报阈值：`tsen scope tune 代码` 按日波动给建议并回放对比，确认后加 `--yes`。
- 联动体检：`tsen scope check`（同业、夜间信号是否变弱，有没有新的强联动候选）。
